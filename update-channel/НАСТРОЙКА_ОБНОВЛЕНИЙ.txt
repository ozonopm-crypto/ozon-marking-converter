Новая установка 1.2.2 уже содержит адрес проверки. Если ранее сохраняли
пустой или другой адрес, откройте настройки обновлений расширения,
вставьте адрес проверки выше и нажмите «Сохранить адрес».

ПРОВЕРКА
Нажмите «Проверить обновления» в окне расширения. Для установленной
версии 1.2.2 ожидается «Новых версий не найдено». Для 1.2.1 с этим же
адресом ожидается сообщение о новой версии 1.2.2 и ссылка на архив.

СЛЕДУЮЩИЙ ВЫПУСК
1. Увеличьте версию в manifest.json, проверьте и соберите архив.
2. Загрузите архив с новым номером в папку downloads репозитория.
   Старые архивы не заменяйте.
3. Обновите version, download_url и notes в корневом updates.json.
   Номер должен совпадать с manifest.json внутри архива.
   Адрес проверки остаётся прежним. Публикуйте метаданные после архива.
4. Проверьте адреса в браузере без входа в GitHub и ручную проверку
   в расширении предыдущей версии.

Сотрудники получают отметку NEW и ссылку на архив при запуске браузера
или примерно раз в 6 часов его работы. Файлы заменяются вручную
в той же папке расширения; после замены перезагрузите расширение
и страницы Ozon. Не удаляйте установку перед обновлением.

Для отключения проверки сохраните пустой адрес. При недоступности GitHub
преобразование кодов продолжает работать локально. Репозиторий должен
оставаться публичным: приватный адрес требует другого механизма доступа.



ENGLISH — EXTENSION UPDATE CHANNEL
by PEI

Repository:
https://github.com/ozonopm-crypto/ozon-marking-converter
Feed:
https://raw.githubusercontent.com/ozonopm-crypto/ozon-marking-converter/main/updates.json

A fresh 1.2.2 install includes the feed. If a blank or custom URL was saved,
enter this URL in the extension's update settings and save it.
Check for updates should report no newer version on 1.2.2. An older
version using the same feed should offer 1.2.2 and its ZIP download.

TO RELEASE AN EXTENSION UPDATE
1. Increase manifest.json version, test, and create the ZIP.
2. Upload a new versioned ZIP into downloads. Keep old archives unchanged.
3. Update version, download_url and bilingual notes in the root updates.json
   and its update-channel copy. The number must match manifest.json in
   the ZIP. Publish the ZIP before its metadata, or publish atomically.
4. Verify public URLs without signing in and check from an older extension.

Staff receive a NEW badge and download link after startup or a periodic
check. Files are replaced manually in the existing installation folder,
then the extension and Ozon tabs are reloaded. Do not remove the installed
extension to upgrade it. Saving an empty feed disables checks.
The repository must remain public for this unauthenticated update channel.
Offline code conversion continues when GitHub is unavailable.
This feed is for the browser extension; Windows uses windows-updates.json.
