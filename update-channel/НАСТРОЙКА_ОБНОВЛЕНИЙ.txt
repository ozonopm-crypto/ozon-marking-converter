ОБНОВЛЕНИЯ ЧЕРЕЗ GITHUB — 1.2.1

Репозиторий: https://github.com/ozonopm-crypto/ozon-marking-converter
Адрес проверки: https://raw.githubusercontent.com/ozonopm-crypto/ozon-marking-converter/main/updates.json
Скачивание: https://raw.githubusercontent.com/ozonopm-crypto/ozon-marking-converter/main/downloads/ozon-extension-1.2.1.zip

Новая установка 1.2.1 уже содержит адрес проверки. Если ранее сохраняли
пустой или другой адрес, откройте настройки обновлений расширения,
вставьте адрес проверки выше и нажмите «Сохранить адрес».

ПРОВЕРКА
Нажмите «Проверить обновления» в окне расширения. Для установленной
версии 1.2.1 ожидается «Новых версий не найдено». Для 1.2.0 с этим же
адресом ожидается сообщение о новой версии 1.2.1 и ссылка на архив.

СЛЕДУЮЩИЙ ВЫПУСК
1. Увеличьте версию в manifest.json, проверьте и соберите архив.
2. Загрузите архив с новым номером в папку downloads репозитория.
   Старые архивы не заменяйте.
3. Обновите version, download_url и notes в корневом updates.json.
   Номер должен совпадать с manifest.json внутри архива.
   Адрес проверки остаётся прежним. Публикуйте метаданные после архива.
4. Проверьте адреса в браузере без входа в GitHub и ручную проверку
   в расширении предыдущей версии.

Сотрудники получают отметку NEW и ссылку на архив при запуске браузера
или примерно раз в 6 часов его работы. Файлы заменяются вручную
в той же папке расширения; после замены перезагрузите расширение
и страницы Ozon. Не удаляйте установку перед обновлением.

Для отключения проверки сохраните пустой адрес. При недоступности GitHub
преобразование кодов продолжает работать локально. Репозиторий должен
оставаться публичным: приватный адрес требует другого механизма доступа.
