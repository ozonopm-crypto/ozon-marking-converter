ОБНОВЛЕНИЯ WINDOWS-ПРОГРАММЫ
by PEI

СОТРУДНИКУ
Один раз установите версию 1.2.0 или новее.
Дальше программа сама проверяет новые версии после запуска и раз в 6 часов.
При новой версии откройте «Обновления» и нажмите «Обновить».
Скачивание, проверка установщика, установка и запуск выполняются программой.
Переносить файлы и заново включать расширения браузера не требуется.

АВТОРУ — ВЫПУСТИТЬ НОВУЮ ВЕРСИЮ
1. Откройте:
   https://github.com/ozonopm-crypto/ozon-marking-converter/actions/workflows/windows-release.yml
2. Выберите Run workflow.
3. Укажите номер ВЫШЕ текущего, например 1.2.1, и кратко опишите изменения.
4. Нажмите зелёную Run workflow и дождитесь успешного завершения.
5. GitHub соберёт установщик, запустит тесты и опубликует:
   downloads/OzonMarkingConverter-Setup-НОМЕР.exe
   windows-updates.json
6. Сотрудники увидят новую версию. Для немедленной проверки можно
   нажать «Проверить обновления» в программе.

Смена номера сама по себе не исправляет программу.
Изменения в исходниках нужно сначала внести и проверить.
После доработки исходников выпуск выполняется описанным способом.

Если Actions отключён в репозитории, владельцу нужно включить его в GitHub.
Токены и пароли сотрудникам склада не нужны.
Выпуски публичные; коды товаров и данные заказов не публикуются.
Не меняйте адрес репозитория и файл windows-updates.json, иначе
установленные программы перестанут находить обновления.

HTTPS и SHA256 проверяют целостность скачанного файла. Это не цифровая
подпись Windows. Недоступный, повреждённый либо старый выпуск не ставится.
